# 《元素之诗》玩法介绍 · 测试版

> 这是一个 **Minecraft 1.21.1 / NeoForge** 模组。
> 一句话：**万物都会衰变，而魔法，是给正在衰变的元素指出一个方向。**
>
> 本版本只做了「衰变 + 采集 + 仓储 + 施法」四块。
> 污染、晶裔、群系这些还没做，所以世界暂时不会变脏，可以放心乱放法术。

---

## 一、5 分钟上手

```
① 去挖矿 / 舀水 / 割草 / 打树叶，拿到「元素瓶」
② 把元素放进密封仓（或者随便哪个箱子），它会慢慢变质
③ 做个仪式台，把元素投进去，写出一块「申明板」
④ 拿着板右键 —— 法术放出来了
⑤ 想打人？把板刻到剑上；想远程？把板刻到书上
```

---

## 二、元素：会变质的东西

元素不是普通的材料，它**有保质期**，而且**不可逆**：

```
稳定元素 ──一段时间──▶ 衍生元素 ──再一段时间──▶ 死寂物质
  火                      烬                     （灰）
```

- 界面里瓶子下面那条细条就是**剩余保质期**
- 变质后用途整个换掉，变不回去
- 最后的「死寂尘 / 死寂物质」不是垃圾，能当建材

### 七种基础元素

| 元素 | 从哪来 | 大概多久变质 |
| --- | --- | --- |
| 火 | 岩浆、营火、火焰 | 12 分钟（基准） |
| 水 | 水方块、雪 | 7.5 分钟 |
| 草 | 草方块、树叶 | 9 分钟 |
| 地 | 石头、沙、矿石 | 16.5 分钟 |
| 风 | 空气（在高处/空旷处） | 13.5 分钟 |
| 光 | 萤石、阳光 | 6 分钟 |
| 暗 | 阴暗处、洞穴 | 6 分钟 |

### 二阶元素是「克制剂」

它们**没有正面作用**，只用来**抵消**某条轴：

| 元素 | 作用 |
| --- | --- |
| 霜 / 冰 | 抵消**火** |
| 砂 / 金 | 抵消**水** |
| 芽 / 木 | 抵消**地** |
| 电 | 抵消**草** |
| 烬 | 抵消**风** |

> 所以「火 + 冰」会互相抵消成 0 —— 这是**湮灭**，什么都不发生，但会留下余热。

## 三、仓储：容器决定寿命

| 容器 | 效果 |
| --- | --- |
| 普通箱子 | 正常变质 |
| **密封仓** | 变质速度 **减半** |
| **元素小包** | 9 格随身，放**霜 / 冰**当燃料可以再减速 |
| **符文柜** | 27 格，**喂霜 / 冰就完全不衰变**，但会慢慢消耗 |

符文柜是中期目标：喂一块霜能撑半天，喂冰撑一天，最多存 8 天。

## 四、仪式台：写一块申明板

界面从上到下：

```
[ 命名（可选） ]
[ 料 ] [ 辅料 ] [ 态 ]
──────────────
[ 申明板 ] → [ 产出 ]
```

| 槽位 | 放什么 |
| --- | --- |
| **料** | 主元素（决定这是什么法术） |
| **辅料** | 第二个元素（和料一起决定反应） |
| **态** | 决定"怎么发生"：火=更痛、风=更大、光=更久、地=造/拆 |
| **申明板** | 放一块**空板**，产出写好的板 |
| 底部格 | 放**修饰材料**（见第六节），也可以空着 |

### 投入数量 = 档位

同一个槽位放 **1 个 / 3 个 / 9 个** 分别是 **1 / 2 / 3 档**。

**档位越高，效果越强**，但：

- 2 档 / 3 档效果是**质变**（比如火：1 档点火 → 2 档带伤害 → 3 档直接爆炸）
- 施法消耗也更高（4 / 8 / 16 点元素值）

### 写单元素法术要注意

想写「只有一种元素」的法术（比如纯火、纯水），**料和辅料两个槽都要放同一种元素**。

## 五、三种形态：板 / 剑 / 书

同一块申明，换个载体就是完全不同的用法：

| 载体 | 怎么做 | 效果 |
| --- | --- | --- |
| **申明板** | 仪式台直接写出来 | 法术**落在自己身上**（适合增益、防护） |
| **申明剑** | 锻造台：板 + 剑 + 粘液球 | 砍谁，法术就落在谁身上 |
| **申明书** | 锻造台：板 + 书 + 粘液球 | 飞出去，**命中才结算** |

> 板子打自己是**故意的**：想自爆、想自愈、想给自己上抗性，就用板。

---

## 六、修饰材料：给法术加一层

把材料放在仪式台**底部那个格子**，再拼贴或写板，就会带上它的效果。

| 材料 | 效果 |
| --- | --- |
| 粘液球 | 没有特别效果（默认） |
| **红石粉** | 两段法术之间**延迟 0.5 秒** |
| **末影珍珠** | 弹射物**没有飞行时间**，指哪打哪 |
| **回响碎片** | 整条法术 **2 秒后重放一次** |
| **糖** | 飞得**又快又远**，但会偏 |
| **紫颂果** | **穿墙**，只打生物 |
| **火药** | 命中后**停 1.5 秒**才结算 |
| **荧石粉** | 命中的目标**发光**，方便追 |
| **龙息** | 命中点留下**魔法烟雾**，雾里持续吃这个法术 |
| **金锭** | **冷却 -30%**，最多叠两个（-60%） |

悬浮申明板 / 剑 / 书，会看到一行「**修饰：…**」告诉你带了什么。

---

## 七、拼贴：把两个法术串起来

把**两块已经写好的板**放进仪式台的「料」和「辅料」位：

```
[ 板 A ] [ 板 B ] ( [  ] )
──────────────
[ 修饰材料 ] → [ 拼贴板 ]
```

- 施法时**先放 A，再放 B**
- 名字会拼起来，比如「点燃 洪流」
- **可以继续拼第三段**（彩虹 → 爆炸 → 浇灌）
- 最多修饰 **3 次**，第 4 次会提示「过于复杂」

配合红石粉，就能做出「延迟 0.5 秒的二连击」。

---

## 八、冷却

每条申明板**各自**有冷却，不是全局的：

| 档位 | 冷却 |
| --- | --- |
| 1 档 | 3 秒 |
| 2 档 | 4 秒 |
| 3 档 | 5 秒 |
| 拼贴 | 再 +1 秒 |

所以多准备几块不同的板，就能连续输出。

## 十、给测试者的几句话

**这个版本还缺什么**：

- 世界不会变脏（污染系统还没做）
- 金、电两种元素暂时拿不到（留给以后）
- 法术飞出去的还是"元素瓶"的样子（美术在重画）

**帮我重点看**：

1. **手感**：冷却长不长？弹射物快不快？击退够不够？
2. **清晰度**：你能看出自己刚才放了什么法术吗？
3. **数值**：3 档值不值那个消耗？
4. **崩溃**：有报错的话，日志发我

**别在意**：贴图、音效、平衡细调 —— 这些还没到打磨阶段。

## 十一、安装

1. Minecraft **1.21.1** + NeoForge **21.1.262**
2. 把 `elemental_verse-0.1.0.jar` 丢进 `.minecraft/mods/`
3. 启动

> 如果启动直接闪退、日志停在 `fmlearlywindow`，是这台机器 LWJGL 原生库的问题，
