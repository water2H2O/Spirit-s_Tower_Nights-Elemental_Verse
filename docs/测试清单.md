## 2. 衰变、耐久条与 tooltip

| # | 操作 | 预期 |
| --- | --- | --- |
| 2.1 | 装一个火元素瓶放背包 | **立刻**出现一条**满格绿色横条**（进度 0 也画） |
| 2.2 | 等几分钟 | 横条**慢慢缩短**，绿→黄→红 |
| 2.3 | 手持元素瓶走动 | **不能闪**（这条踩过两次坑） |
| 2.4 | 空瓶 | **没有横条** |
| 2.5 | 火元素 → 等 12 分钟 | 变成**烬**（图标变），计时条按新阈值重算 |
| 2.6 | 烬 → 再等 24 分钟 | 变成**死寂尘** |
| 2.7 | 光元素放亮处 vs 暗处 | 亮处**明显更久**（6 分钟 → 12 分钟） |
| 2.8 | 把两叠同元素、不同剩余时间的瓶子合并（采集时自动并） | 剩余时间变成**加权平均** |
| 2.9 | 手动把一叠拆开放两个格子 | **不会被自动合并回去** |
| 2.10 | 悬停元素瓶 | 显示模糊阶段：<br>新装 →「尚有余韵」<br>过半 →「渐趋沉寂」<br>快到头 →「行将死寂」<br>空瓶 →「一个空瓶子」；金 →「这个形态不会再变了」<br>**不显示数字** |
| 2.11 | 把火元素放进普通箱子，等 12 分钟 | 变成烬；不会因为视距大/区块多而变成两小时 |

## 4. ⭐ 仪式台（写入 / 刻印）

| # | 操作 | 预期 |
| --- | --- | --- |
| 4.1 | 合成仪式台（8 石头 + 1 死寂尘） | 能造出来 |
| 4.2 | 放下仪式台 | **正面朝向自己**（有朝向） |
| 4.3 | 右键 | 界面打开，**底图是作者的图**，槽位**对得上** |
| 4.4 | 界面布局 | 上排三个格（主料 / 辅料 / 态）、左下申明板、**中间剑槽（有槽位框和「剑槽」字样）**、右下产出、下方背包 |
| 4.5 | 放**空申明板 + 1 个火** | 右下出现「**点燃**申明板」 |
| 4.6 | 放 **1 个火 + 1 个水（辅料）** | 右下变成「**蒸汽**申明板」 |
| 4.7 | 放 **9 个火** | 产出改成 3 档（悬停看浓度） |
| 4.8 | 拿走产出 | 板子、主料、**辅料、态**都按档位扣掉（档 3 各扣 9 个） |
| 4.9 | 放入**已写好的**板子 + **一把剑** | 剑槽旁的产出变成**带申明的剑** |
| 4.10 | 拿走刻好的剑 | **原剑被消耗**，申明板**保留**；不能反复取出剑副本 |
| 4.11 | 仪式台紧挨箱子，箱里放火，主料槽空 | 能产出；拿走产出后**箱子里的火会被扣掉**，不是白拿 |
| 4.12 | 产出格有预览时直接砸掉仪式台 | 只掉输入/板子，**不掉产出**（不能靠拆台子白拿） |
| 4.13 | 放入**已写好的**板子，但剑槽空 | 产出格**不产出** |
| 4.14 | 对产出格 **shift-click** | 可能会连续做多份（每份都扣材料）；不能靠 shift-click 白拿 |

> 写入消耗：主料 + 辅料 + 态 + 1 张空板。
> 刻印消耗：剑（板是模板，不消耗）。
> 释放消耗：主料 + 辅料；态已经在写板时付过，不按次扣。

## 5. ⭐ 申明板与施法

| # | 操作 | 预期 |
| --- | --- | --- |
| 5.1 | 看板子名字 | 「蒸汽申明板」这类**魔法名**，不是「火申明板」 |
| 5.2 | 悬停 | 金色魔法名 + 料 + 浓度 + 形 + 态（如果有） |
| 5.3 | 手持**点燃**板右键空地 | 面前**起火** |
| 5.4 | 手持**蒸汽**板对着生物右键 | 小伤害 + **被击退**（朝远离施法者方向） |
| 5.5 | 手持**熔岩**板对着地面右键 | 命中面上**出现岩浆** |
| 5.6 | 手持**火焰保护**板右键 | 自己身上出现**抗火**，约 **10 秒**（JSON duration 200 tick） |
| 5.7 | 背包里**没有**对应元素瓶时右键 | 行为栏提示「X 不够了」，**不施法** |
| 5.8 | 施法一次 | 主料 + 辅料被扣（各按档位 1/3/9）；态不扣 |
| 5.9 | 用 1 个草（凑不出反应）的板子右键 | 提示「这些元素凑不出反应」，**不扣材料** |
| 5.10 | 手持**强光**板（主料 **3 个光**，档 2）对着生物右键 | **生物**失明；施法者自己不失明 |
| 5.11 | 给剑刻上**燃烧**，攻击生物 | 着火/伤害落在**被打中的生物**上，不会烧到面前的地板或另一个实体 |
