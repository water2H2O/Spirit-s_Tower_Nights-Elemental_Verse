## 2. 衰变与耐久条

| # | 操作 | 预期 |
| --- | --- | --- |
| 2.1 | 装一个火元素瓶放背包 | 底下出现**一条绿色横条** |
| 2.2 | 等几分钟 | 横条**慢慢缩短**，绿→黄→红 |
| 2.3 | 手持元素瓶走动 | **不能闪**（这条踩过两次坑） |
| 2.4 | 空瓶 | **没有横条** |
| 2.5 | 火元素 → 等 12 分钟 | 变成**烬**（图标变），计时条按新阈值重算 |
| 2.6 | 烬 → 再等 24 分钟 | 变成**死寂尘** |
| 2.7 | 光元素放亮处 vs 暗处 | 亮处**明显更久**（6 分钟 → 12 分钟） |
| 2.8 | 把两叠同元素、不同剩余时间的瓶子合并（采集时自动并） | 剩余时间变成**加权平均** |
| 2.9 | 手动把一叠拆开放两个格子 | **不会被自动合并回去** |
