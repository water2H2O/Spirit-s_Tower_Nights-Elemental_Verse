# 拼贴与修饰材料（设计稿）

> 2026-10-21 作者口述，尚未实现。
> 这一版同时承担了路线图里「附属材料」和「时序」两个职责。

---

## 一、一句话

> 把两块**已经写好**的申明板拼在一起，再放一份**修饰材料**决定它们怎么衔接。

---

## 二、仪式台的新用法（拼贴模式）

现有的「写入模式」不变：空板 + 三份元素 → 一块写好的板。

新增「拼贴模式」，槽位含义换成：

```
        [ 命名框 ]
   [ 板 1 ] + [ 板 2 ] ( [ 空 ] )
   ────────────────────────────
   [ 修饰材料 ]  →  [ 拼贴板 ]
```

| 槽位 | 写入模式 | 拼贴模式 |
| --- | --- | --- |
| 料（第一个） | 元素 | **板 1** |
| 辅料（第二个） | 元素 | **板 2** |
| 态（第三个） | 元素 | 留空 |
| 空板位 | 空申明板 | **修饰材料** |
| 产出 | 写好的板 | 拼贴板 |

**执行顺序：先放第一个，再放第二个。**

---

## 三、修饰材料

和锻造台现在用的**粘液球**是同一类东西 —— 也就是"贴在申明板上的一层附加物"。

| 材料 | 效果 | 备注 |
| --- | --- | --- |
| **粘液球** | 默认：两块板**同时**生效 | 相当于没修饰 |
| **红石粉** | 两段法术之间**延迟 0.5 秒** | 通常配合"空板"做纯延时 |
| **末影珍珠** | 允许修饰**单块**板：形态为「发射」时，**立即对路径上第一个目标生效**（准即时命中） | 也可以用在拼贴板上 |

### 空板占位

允许把**空的申明板**放进"板 2"——代表"什么都不做"。

这样 `红石粉 + 板 + 空板` 就等于「延时 0.5 秒后放一次法术」，
以后做更复杂的序列（三段、四段）也用同一套规则。

---

## 四、修饰次数上限

**同一块申明板最多被修饰 3 次。**

- 第 4 次时提示「过于复杂」，不消耗材料
- 这个上限同时是"偏差系统"的替代品：越复杂越难做，而不是越容易跑偏

## 五、待定的细节（实现前要拍板）

1. **拼贴板的形态取谁？**
   - 取板 1 的形态（板 2 的执行方式跟着板 1）
   - 还是两块各按自己的形态执行（板 1 自身 + 板 2 发射，同时成立）

2. **拼贴消耗什么？**
   - 两块板都消耗？
   - 只消耗第二块（第一块当"模板"）？

3. **三次上限的作用对象**
   - 每块**实体板**（物品）最多 3 次
   - 还是"一条法术链"上最多 3 层

4. **红石粉在单块板上**
   - 没有第二段可延迟 → 是无效、还是"延迟 0.5 秒后才放"？

5. **末影珍珠的命中判定**
   - 改成"碰到第一个目标立即结算并消失"
   - 还是"碰到就结算，但继续飞"

6. **修饰材料是否也是锻造台的材料**
   - 锻造台现在用粘液球作 addition，要不要也支持红石粉 / 末影珍珠
