# 拼贴与修饰材料（设计稿）

> 2026-10-21 作者口述，尚未实现。
> 这一版同时承担了路线图里「附属材料」和「时序」两个职责。

---

## 一、一句话

> 把两块**已经写好**的申明板拼在一起，再放一份**修饰材料**决定它们怎么衔接。

---

## 二、仪式台的新用法（拼贴模式）

现有的「写入模式」不变：空板 + 三份元素 → 一块写好的板。

新增「拼贴模式」，槽位含义换成：

```
        [ 命名框 ]
   [ 板 1 ] + [ 板 2 ] ( [ 空 ] )
   ────────────────────────────
   [ 修饰材料 ]  →  [ 拼贴板 ]
```

| 槽位 | 写入模式 | 拼贴模式 |
| --- | --- | --- |
| 料（第一个） | 元素 | **板 1** |
| 辅料（第二个） | 元素 | **板 2** |
| 态（第三个） | 元素 | 留空 |
| 空板位 | 空申明板 | **修饰材料** |
| 产出 | 写好的板 | 拼贴板 |

**执行顺序：先放第一个，再放第二个。**

---

## 三、修饰材料

和锻造台现在用的**粘液球**是同一类东西 —— 也就是"贴在申明板上的一层附加物"。

| 材料 | 效果 | 备注 |
| --- | --- | --- |
| **粘液球** | 默认：两块板**同时**生效 | 相当于没修饰 |
| **红石粉** | 两段法术之间**延迟 0.5 秒** | 通常配合"空板"做纯延时 |
| **末影珍珠** | 允许修饰**单块**板：形态为「发射」时，**立即对路径上第一个目标生效**（准即时命中） | 也可以用在拼贴板上 |

### 空板占位

允许把**空的申明板**放进"板 2"——代表"什么都不做"。

这样 `红石粉 + 板 + 空板` 就等于「延时 0.5 秒后放一次法术」，
以后做更复杂的序列（三段、四段）也用同一套规则。

---

## 四、修饰次数上限

**同一块申明板最多被修饰 3 次。**

- 第 4 次时提示「过于复杂」，不消耗材料
- 这个上限同时是"偏差系统"的替代品：越复杂越难做，而不是越容易跑偏

---

## 五、已拍板的规则（2026-10-21）

| # | 问题 | 结论 |
| --- | --- | --- |
| 1 | 拼贴板的形态取谁 | **取第一块**；名字 = 两块魔法名**拼接** |
| 2 | 消耗什么 | **两块板都消耗**，产出一块拼贴板 |
| 3 | 修饰次数怎么算 | `max(两块各自的次数) + 1`；超过 3 → 提示「过于复杂」，不产出 |
| 4 | 空板纯延时 | **取消**，不再支持空板占位 |
| 5 | 末影珍珠 | **没有飞行时间**，直接命中准星指向的位置（指哪打哪） |
| 6 | 锻造台 | **也支持**红石粉 / 末影珍珠作为 addition |

> 次数示例：一块修饰过 2 次的板 + 一块修饰过 1 次的板 → 新板算 **3 次**（max(2,1)+1）。
