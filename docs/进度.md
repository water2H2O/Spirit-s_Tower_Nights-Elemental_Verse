## 三、05 阶段的真实缺口

路线图要求四件事，目前只有半件：

| 要求 | 现状 |
| --- | --- |
| **形态**：自身 / 发射 / 交互 | ⚠️ 只有「发射」可用。`self` 有代码分支但**没有任何写入途径**；`touch` 被统一成了发射 |
| **附属材料十种** | ❌ 未做。现在的"辅料"是任意元素，不是稳定 / 延时 / 冷凝那十种 |
| **时序**：即时 / 延时 / 持续 | ❌ 未做 |
| **偏差系统 + 四种跑偏** | ❌ 未做 |
| **知识解锁**（调试指令） | ❌ 未做 |
| **申明板读回** | ⚠️ 只有 tooltip，没有"右键读" |

> 注意：`二级元素负值化` + `三级递进` + `双元素附加` 这三套是**路线图里没有的**，
> 它们部分替代了「附属材料」的职能（用元素本身当修饰）。
> 阶段 05 的策划案需要按现状重写，而不是照抄原条目。
