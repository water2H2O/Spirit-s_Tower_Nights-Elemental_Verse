## 三、05 阶段：拼贴 + 修饰材料（2026-10-21 完成）

这一层同时承担了原路线图里「附属材料」和「时序」两个职责 —— 法术从「一次性配方」变成**可组合的句子**。

### 三种形态（早就有了）

板 = **自身**、剑 = **接触**（锻造台）、书 = **发射**（锻造台）。

### 拼贴模式（仪式台的新用法）

| 槽位 | 写入模式 | 拼贴模式 |
| --- | --- | --- |
| 料（第一口） | 元素 | **板 1** |
| 辅料（第二口） | 元素 | **板 2**（可以放空板 = 什么都不做） |
| 态（第三口） | 元素 | 留空 |
| 空板位 | 空申明板 | **修饰材料** |
| 产出 | 写好的板 | 拼贴板 |

执行顺序：**先放第一块，再放第二块**。

### 三种修饰材料

| 材料 | 效果 |
| --- | --- |
| **粘液球** | 默认：两段法术**同时**生效 |
| **红石粉** | 两段之间**延迟 0.5 秒**（10 tick） |
| **末影珍珠** | 弹射物形态改为**指哪打哪**（无飞行时间，立即对路径上第一个目标生效） |

### 规则

- **同一块板最多修饰 3 次**；第 4 次直接提示「过于复杂：这条法术已经修饰过 3 次」，不消耗材料
- **空板占位**合法：`红石粉 + 板 + 空板` = 「0.5 秒后放一次法术」，三段四段将来用同一套规则
- 数据结构上是一块板里套着第二块板（`Declaration.second` + `modifier` + `modified`），
  延迟法术走 `PendingCasts` 队列，到点在原位置结算

### 现在能拼出什么

```
冰（1 档）+ 火（3 档） + 板      → 冻住，再炸一下
红石粉 + 板(木) + 板(火)         → 0.5 秒后炸 —— 炸完人还没落地
末影珍珠 + 书(风 > 水)           → 发射即命中，不用等飞到
```
