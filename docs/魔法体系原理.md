# 魔法体系原理

> **这份文档管"世界为什么是这样"，不管"这一步做什么"。**
> 阶段策划（`分阶段/04-仪式台与申明板.md`）是它的实现；冲突时以本文档为准。
>
> 版本：第 1 版（2026-10-18）
> 定调：作者要求"魔法体系尽可能自由"，因此设计成**可计算的化学式**，
> 并在此基础上补了**料/形分离、主成分律、守恒三律、发现机制**四块。

---

## 一、一句话原理

> ## 魔法 = 给正在衰变的元素值，指出一个方向。

世界本身在衰减（这是模组的核心设定：万物都在往死寂去）。
衰减会释放出"元素值" —— 那是世界的**势能**。

但势能自己**只会均匀散掉**，变成余热，做不了任何有用的事。

**申明板是"形"**：它告诉这股势能往哪个方向释放。
没有形，元素值散成余热；有了形，它才变成火球、冰墙、治愈。

---

## 二、三条推论（世界因此是什么样子）

| 现象 | 为什么必然如此 |
| --- | --- |
| **施法必须消耗元素** | 你在借衰变的势能，不是凭空造。没有料就没有势差 |
| **施法一定留余热** | 没被"形"引导的那部分势能，就是脏东西 |
| **申明写不清会跑偏** | 形不明确，势能就按它自己的方式散 —— 不是失败，是**散错地方** |
| **死寂尘是终点** | 势能被榨干之后的样子 |
| **晶裔收集"形"** | 元素世界遍地都是，**形**才是唯一不会自然产生的东西 |

> 这一条原理**没有新增任何设定**。它只是把已经存在的六个系统
> （衰变 / 余热 / 死寂尘 / 申明板 / 纯净度 / 晶裔）用一句话解释了。

## 三、料与形：魔法 = 质料 × 形式

这是整套体系的骨架，也是"自由"的来源。

| | 决定什么 | 载体 | 玩家的感受 |
| --- | --- | --- | --- |
| **料** | 能做**多大**的、**什么类**的事 | 元素值（6 轴，可计算） | "我有多少料" |
| **形** | **怎么**作用：打向哪、什么时候、多大范围 | 申明板上的字段（知识） | "我会哪些写法" |

### 3.1 为什么必须分开

**① 化学式只能描述"料"，描述不了"法"。**
`{草:1, 火:1}` 能说明"这是一团带生命力的火"，但说不出它是**丢出去**还是**附在身上**。
方向、时机、范围、结构，这些都不是"量"，装不进六维向量里。

**② 加新魔法不该动元素值。**
如果所有魔法都必须在 6 维空间里找位置，那维度就是天花板。
分开之后：**加一条形 = 加一种魔法**，元素值一条都不用改。

**③ 玩家学的是语法，不是配方。**
7 种料 × N 种形 = 组合空间，但记忆量是**加法**的（学会"发射"这一种形，所有料都能发射）。
这才是"自由"的体验：不是"记住了很多配方"，而是"会说话了"。

**④ 它让总纲 5.5 那句话有了落点。**
"模糊的申明比错误的申明更危险" ——
料永远够用，**跑偏一定是形没写清**。

### 3.2 分工的硬边界

| 归料管 | 归形管 |
| --- | --- |
| 元素轴的构成 | 形态：自身 / 发射 / 交互 |
| 强度（能做多大） | 时序：即时 / 延时 / 持续 |
| 是否含负分量（能不能"吸"） | 状态：松手即停 / 元素场不足 / 超出范围 |
| 组合后的主成分 | 附属修饰：稳定 / 延长 / 相位 … |

> **不要把形塞进元素值里**（比如"造一个叫发射的元素"）—— 那会把两个正交的维度压平，
> 直接退回死角。

## 四、料：元素值

### 4.1 六条基础轴

```
火 fire · 水 water · 地 earth · 风 wind · 草 grass · 光 light
```

**暗不是独立轴，是负的光**（`{光: -1}`）。
所以"光 + 暗 = 0"是天然成立的，不需要任何特判。

### 4.2 元素 = 式子

| 元素 | 元素值 | 性质 |
| --- | --- | --- |
| 火 | `{火:1}` | 稳定 |
| 水 | `{水:1}` | 稳定 |
| 地 | `{地:1}` | 稳定 |
| 风 | `{风:1}` | 稳定 |
| 草 | `{草:1}` | 稳定 |
| 光 | `{光:1}` | 稳定 |
| **暗** | `{光:-1}` | 负光 |
| **霜** | `{水:1, 火:-0.5}` | 带负火 → 吸热（作者已定） |
| 冰 | `{水:1, 火:-1}` | 更强的吸热 |
| 砂 | `{地:1, 水:-0.5}` | 干（带走水） |
| 电 | `{风:1, 光:0.5}` | 动 + 明 |
| 烬 | `{火:1, 光:-0.5}` | 暗火 |
| 芽 | `{草:1, 水:0.5}` | 生 + 湿 |
| 木 | `{草:2}` | 凝聚的生命 |
| 晨 | `{光:1, 火:0.5}` | 明 + 暖 |
| 影 | `{光:-1, 草:-0.5}` | 负光 + 负生 |
| 金 | `{地:2, 火:1}` | 重 + 韧（本期不产出） |

> **二级元素不是"另一种元素"，是分子。**它们的意义在于**组合会产生新东西**。
> 具体数值后续可调，但**越早定越好** —— 它决定了"什么和什么混在一起会长出什么"。

### 4.3 强度

**强度 = 各分量绝对值之和**

| 元素 | 强度 |
| --- | --- |
| 火 | 1 |
| 霜 | 1.5 |
| 冰 | 2 |

强度用来**缩放现象的强弱**和**判断是否达到饱和**，不直接决定扣几个瓶
（扣瓶数由反应式的"消耗"决定）。

## 五、主成分律：让组合可预测

### 5.1 法则

> **投入的总向量里，绝对值最大的那条轴决定现象的"类别"；其余分量只做修饰。**

如果最大轴有并列，按固定优先级裁决：`火 > 水 > 草 > 地 > 风 > 光`。

如果所有分量归零（例如 `{光:1} + {光:-1}`）→ **不产生现象**，那叫**湮灭**。

### 5.2 为什么需要它

化学式最大的体验风险是"我不知道能做什么"。
如果每条组合都要查表，玩家感受到的不是自由，是**随机**。

主成分律给了玩家一个**能自己推的直觉**：

| 投进去 | 主成分 | 玩家预期 |
| --- | --- | --- |
| `{草:1, 火:1}` | 火（并列，火优先） | 带生命力的火 |
| `{火:3, 草:1}` | 火 | 更大的火 |
| `{水:1, 火:-0.5}`（霜） | 水 | 水类，但带负火 → **吸热** |
| `{火:1, 水:-1}` | 火（与负水） | 火类，且把水抽干 → **焦灼** |

**有了这一条，化学式的"自由"才变成"可玩"。**

### 5.3 轴 → 现象类别

| 轴 | 正面 | 负分量带来的"反向"性质 |
| --- | --- | --- |
| 火 | 热、燃烧、爆 | 负火 → 吸热、降温 |
| 水 | 湿、流、溶 | 负水 → 干燥、龟裂 |
| 草 | 生长、愈合、缠绕 | 负草 → 枯萎、腐朽 |
| 地 | 坚硬、重量、塑造 | 负地 → 松散、崩解 |
| 风 | 移动、推开、加速 | 负风 → 停滞、束缚 |
| 光 | 照亮、揭示 | 负光 → 遮蔽、隐匿 |

> **负分量是这套体系的特色**：它让"降温"不是水的属性，而是"负火"的属性。
> 所以任何带负火的东西都能降温 —— 霜、冰、某些烬变体都行。

## 五之二、三个投入口 = 三次查表（不是三阶排列）

一开始担心的"组合爆炸"在这里被解掉了：**三个格子不是三阶笛卡尔积，是三次独立查询。**

| 格子 | 角色 | 决定什么 | 查哪张表 |
| --- | --- | --- | --- |
| **第 1 口** | **主料** | 效果的**类别**与基础强度 | 轴 → 现象类别（第五节） |
| **第 2 口** | **辅料** | 与主料**反应**（相生 / 相消） | 亲和矩阵（第六节） |
| **第 3 口** | **态** | 现象的**参数**：怎么发生 | 六轴参数表（本节） |

```
组合数是乘法：6 × 6 × 6 = 216
工作量是加法：6 + 6 + 6 = 18 条定义
```

> **作者 2026-10-18 定调**：第三个投入口**仍然是元素投入**，
> 但它不贡献强度，而是决定"态"。

### 六轴 → 六个参数

| 态轴 | 参数 | 玩家心里的问题 | 正面取值 | 负分量 |
| --- | --- | --- | --- | --- |
| **火** | **烈度** | 要多疼？ | 更烫、伤害更高 | 更冷（近似冷却） |
| **风** | **范围** | 要多广？ | 扩散：范围大、浓度稀 | 汇聚：范围小、浓度高 |
| **光** | **持续时间** | 要多持久？ | 更久 | 更短，趋近瞬时 |
| **地** | **造 / 拆** | 留东西还是拆东西？ | **造物**：留下实体 | **破坏**：拆掉方块；等级决定范围 |
| **水** | **传播** | 一个人还是一群？ | **连锁**：跳到相邻目标 | 只作用于单体 |
| **草** | **极性** | 是伤还是治？ | **愈疗**：翻成治疗 | **枯萎**：额外伤害 |

### 数据（第一版数值，直接可调）

| 参数 | 档 1（≥1 个） | 档 2（≥3 个） | 档 3（≥9 个） |
| --- | --- | --- | --- |
| 火 · 烈度 | ×1.0 | ×2.0 | ×3.5 |
| 风 · 半径 | 1.5 格 | 3 格 | 5 格 |
| 光 · 持续 | 2 秒 | 5 秒 | 12 秒 |
| 地 · 造/拆半径 | 1 格 | 2 格 | 3 格 |
| 水 · 连锁 | +1 个目标 | +2 个目标 | +4 个目标（跳 4 格） |
| 草 · 治疗比例 | 30% | 60% | 100% |

### 三条配套规则

1. **档位是门槛制**：投入**达到** 1 / 3 / 9 个才进入档 1 / 2 / 3（不是 1 个就 1 档、2 个就 2 档）
2. **第三口放负值元素（暗）→ 参数取反**：所以"光当态"是长时燃烧，"暗当态"是一闪即灭的爆燃
3. **第三口与第一口同元素** → 只算**烈度加倍**，不重复计参数
4. **第三口空着** → 参数取默认（中等烈度、1.5 格、瞬时、不造不拆、单体、纯伤害）

### 为什么这样最省

- 三个格子各查各的表，**加新元素只加一行，不产生新组合**
- 现象的实现只读参数（`intensity / radius / duration / radius2 / chain / polarity`），
  不再关心"是哪个元素给的这个数"
- 以后加新的态轴或新的现象，两边互不影响

## 五之三、主料 × 辅料：28 条效果表（作者 2026-10-18 定稿）

**每个基础元素自己带一个基础效果**（单独当主料时就是它）：

| 轴 | 基础效果 |
| --- | --- |
| 火 | 伤害 |
| 水 | 击退 |
| 地 | 减速（也是"塑形"：造/拆） |
| 风 | 扩散 |
| 草 | 持续 |
| 光 | 神圣 / 治疗 |
| 暗 | 削弱 / 诅咒 |

### 光和暗是「状态轴」

> **火/水/地/风/草 作用于「世界与身体」；光/暗 作用于「状态」（增益 / 减益）。**

这条一定，暗列就不用一条条想 —— 它永远是"给目标挂一个负面状态"。

### 总表（上三角：主料 ↓ × 辅料 →）

| 主料 \ 辅料 | 火 | 水 | 地 | 风 | 草 | 光 | 暗 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| **火** | 火球（火焰伤害） | 蒸汽（小火伤 + 击退） | 熔岩（中火伤 + 减速） | 爆燃（大范围中等火伤） | 燃烧（持续火伤） | **火焰保护** | **阴燃**（不可扑灭的持续火伤） |
| **水** | | 洪流（中等击退 + **锁定物品栏**） | 泥泞（击退 + 减速） | 暴风雪 | 浇灌 | **彩虹**（清负面 + 治疗 + 彩色粒子） | **冰冻** |
| **地** | | | 岩壁（3×3 石头） | 沙尘 | 沃土 | **抗性提升**（最高 3 级） | **易伤**（自创，最高 3 级） |
| **风** | | | | 疾风（更强推力） | 孢子 | **闪现** | **反胃**（+ 自创粒子） |
| **草** | | | | | 再生（持续类效果时长翻倍、等级 +1，好坏都算） | **光合** | **凋零** |
| **光** | | | | | | 强光（致盲 + 照明） | **湮灭**（互相抵消，只产生余热） |
| **暗** | | | | | | | **暗渊**（随机 5 个负面状态 + 固定黑暗） |

### 状态轴的落法（实现口径）

| 效果 | 怎么做 |
| --- | --- |
| 火焰保护 | 原版 `fire_resistance` |
| 抗性提升（1-3 级） | 原版 `resistance`，amplifier 0/1/2 |
| 再生 / 光合 | 原版 `regeneration` |
| 凋零 | 原版 `wither` |
| 反胃 | 原版 `confusion` + 自创粒子 |
| 黑暗（暗渊固定给） | 原版 `darkness` |
| **易伤**（地×暗） | **自创 MobEffect**：受到伤害 ×(1 + 0.15×等级) |
| **冰冻**（水×暗） | 原版机制 `setTicksFrozen`（粉雪冰冻那套） |
| **锁定物品栏**（水×水） | 给目标背包里每件物品上"使用冷却"（等价于盾牌被斧头破盾后的冷却） |
| **暗渊**（暗×暗） | 从原版负面效果里**随机给 5 个** + 固定 `darkness` |

> **易伤**是这套体系里第一个自创状态，所以要注册一个 MobEffect。
> 其余全部复用原版 —— 这也是"下层复杂、玩家看到简单"的一部分：
> 玩家认得的图标越多，学习成本越低。

### 三条补充规则

1. **对角线（7 条）是"单独用"的基础法术**，不是组合，所以核心组合只有 **21 条**
2. **同料叠加**（火+火、水+水…）走"烈度加倍"，但水+水和草+草有专门效果（见上表对角线）
3. **光 × 暗 = 湮灭**：因为暗就是负光，`{光:+1} + {光:−1} = 0` 是加法自己算出来的，
   不需要特判；归零时只产生余热（这是最好的"污染制造机"）

## 六、形：申明板上的字段

形属于**知识**，有解锁节奏（总纲第五章）。

| 字段 | 取值 | 说明 |
| --- | --- | --- |
| **形态** | 自身 / 发射 / 交互 | 效果落在谁身上 |
| **时序** | 即时 / 延时 N / 持续 N | 什么时候、多久 |
| **状态** | 松手即停 / 元素场不足即停 / 超出范围即停 | 什么时候收场 |
| **附属** | 稳定 / 延长 / 相位 / 急速 / 冷凝 … | 修饰（用料里的其他元素值支付） |

**默认状态：松手即停。**

## 七、反应式：料与形的结合

### 7.1 结构

```
消耗：{元素值}
条件：无 / 纯净度阈值 / 目标状态
现象：由主成分决定类别，强度由总元素值缩放
形：  形态 + 时序 + 状态
返还：无 / 某些元素值或物品
```

### 7.2 作者的第一个反应式

```
消耗：1 草 + 1 火
条件：无条件
现象：造成大量持续的火元素伤害
形：  发射 · 即时
返还：无
```

### 7.3 匹配：两级

| 优先级 | 方式 | 例子 |
| --- | --- | --- |
| **1. 精确配方** | 输入向量与反应式的消耗相等（容差 0.01） | `{草:1, 火:1}` → 燃烧 |
| **2. 主成分兜底** | 没有精确配方时，按主成分律生成一个**通用现象** | `{火:5}` → 按火类缩放 |

> 第二级是"自由的保证"：玩家永远可以"扔一堆火"得到一个大火，
> 而不是对着"没有对应配方"发呆。

### 7.4 数据驱动

反应表放 `data/elemental_verse/reaction/*.json`，加魔法只写 JSON。

## 八、守恒三律（防失衡）

化学没有守恒就变成许愿机。

| 法则 | 内容 | 数值建议 |
| --- | --- | --- |
| **守恒** | 现象的"元素值当量"**不得超过**投入的强度 | 当量 ≤ 强度 × 1.0 |
| **饱和** | 单次投入超过阈值后**不再线性变强**，多出的部分转成余热 | 阈值 = 值 3（9 个） |
| **余热** | 每次反应留下废料，按偏离纯净度加重 | 余热 = 强度 × (2 − 纯净度) |

> **饱和**这条最重要：它让"多投料"变成有上限的投入，
> 而不是"64 个火 = 秒天秒地"。超出的部分不是浪费，是**变成污染**。

## 九、发现机制

三种途径，都要有 —— 缺任何一种，"自由"都会变成"不知道能干什么"。

| 途径 | 内容 | 作用 |
| --- | --- | --- |
| **顿悟** | 第一次凑出有效组合 → 提示 + 永久记入图鉴 | 奖励试错 |
| **残卷 / 遗迹** | 直接解锁某条形或某条反应 | 探索回报（总纲的灾变前遗迹） |
| **试验台** | 放料进去预览"大概会是哪一类现象"，**不给数值** | 把试错从惩罚变成探索 |

**以及一个必须有的东西：反应图鉴。**
玩家要能查"我见过哪些组合、结果是什么"——否则第二次就忘了。

## 十、与已有系统的关系

| 已有系统 | 在这套原理里的角色 |
| --- | --- |
| **衰变** | 势能的来源。没有衰变就没有魔法 |
| **余热** | 没被引导的势能 = 熵 |
| **死寂尘** | 势能耗尽后的终点 |
| **纯净度** | 引导效率：越纯，越少变成余热 |
| **申明板** | **形**的载体，也是知识的载体 |
| **晶裔** | 收集"形"—— 唯一不会自然产生的东西 |
| **环境元素**（总纲 12.2） | 势能在世界上的**分布** |

## 十一、加新魔法前的自检清单

每次设计一条新反应，过一遍：

- [ ] 它主要靠哪条轴？主成分是谁？
- [ ] 它需要什么**形**？这个形是否已经存在？（不需要新形就别加）
- [ ] 现象的当量 ≤ 投入强度吗？
- [ ] 它会不会成为**唯一最优解**（性价比碾压一切）？
- [ ] 玩家**怎么发现**它？（顿悟 / 残卷 / 试验台）
- [ ] 它和已有反应会不会**撞车**（同样的输入出不同结果）？
