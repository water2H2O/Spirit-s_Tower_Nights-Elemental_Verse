## 三、画好之后怎么接

**一条命令**，不要手动复制：

```cmd
python tools\integrate-textures.py "<素材包.zip>" <版本名>
```

它会按固定顺序做六件事（复制 → 载体基底 → 重建分发 → 方块物品模型 → 元素瓶修图 → 归档），
其中「重建分发」和「方块物品模型」两步专门防"素材把关键 JSON 覆盖掉"这个坑，
`static-check.py` 里也有对应的硬检查兜底。
