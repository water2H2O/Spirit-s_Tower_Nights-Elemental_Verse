## 二、现在就要（阶段 04 卡在这里）

### 2.1 物品图标（16×16 PNG）

| # | 文件 | 用途 | 不给会怎样 |
| --- | --- | --- | --- |
| **1** | `textures/item/declaration_plate.png` | **空申明板**：一片没写字的石板 | 现在拿紫水晶碎片顶着，看不出是"板" |
| **2** | `textures/item/declaration_plate_written.png` | **已写申明板**：同一块板，但刻上了字/纹 | 现在空板和写好板**长得一样**，玩家分不出哪块能用 |

> **省力方案（推荐）**：第 2 张不用画 17 个元素版本。
> 画**一张通用的"已写"底版**（刻满纹路、中间留一块空白区域），
> 我在代码里按元素给那块空白**染色**（水=蓝、火=红、光=金…）。
> 这样你只交 1 张图，17 种元素自动区分。

### 2.2 方块贴图（16×16 PNG ×3）

| # | 文件 | 用途 |
| --- | --- | --- |
| **3** | `textures/block/ritual_altar_side.png` | 仪式台**侧面**：石台身 |
| **4** | `textures/block/ritual_altar_top.png` | 仪式台**顶面**：中间**凹槽**（放申明板）+ 三个小坑（元素投入口） |
| **5** | `textures/block/ritual_altar_front.png` | 仪式台**正面**（密封仓也是四向朝向，这里沿用同一套） |

> 现在是深板岩 + 死寂顶面拼的**占位**。顶面那张最重要 ——
> 它决定玩家能不能一眼看懂"这里是放料的地方"。

### 2.3 界面（176×166）

| # | 文件 | 内容 |
| --- | --- | --- |

## 五、规格约定

| 项 | 规格 |
| --- | --- |
| 物品图标 | **16×16 PNG**，二值透明，无抗锯齿、无半透明过渡 |
| 方块贴图 | **16×16 PNG**，同样二值透明 |
| 界面 | **176×166**（画布 176×166 或 256×256 都行，告诉我用哪种） |
| 文件名 | 全小写 + 下划线，与上表一致 |
| 音频 | **Ogg Vorbis，单声道**，峰值 -3 dBFS 左右 |

**放哪**：按上表路径丢进 `src/main/resources/assets/elemental_verse/` 对应目录，
然后跑一条命令接入（会顺手重建分发模型、防止关键 JSON 被盖掉）：

```cmd
python tools\integrate-textures.py "<素材包.zip>" v8
```
