## 一、这是什么

一个 Minecraft 1.21.1 / NeoForge 的模组：**万物都会衰变的元素世界**。

核心设定一句话：

> **元素会自然衰变，最终归于死寂；而魔法，是给正在衰变的元素值指出一个方向。**

玩家采到元素 → 装进瓶子（会变质）→ 用仪式台写成「申明」→ 申明变成法术 →
法术会留下余热、会污染环境（阶段 06 接瘴素）。

## 三、已经做完的六大系统

| 系统 | 玩家看到的东西 | 关键类 |
| --- | --- | --- |
| **衰变** | 瓶子底下的耐久条慢慢缩短，元素按链变质，最终成死寂尘 | `DecayEngine` `ElementType` |

| **余热** | 现在看不见；`/ev heat` 可查 | `heat/ChunkHeat` |

## 四、一次施法的完整数据流

```
仪式台三口                 申明板                   施法
────────────────────────────────────────────────────────────
① 主料 ─┐
② 辅料 ─┼─▶ 输入向量 ──▶ 匹配反应 ──▶ 现象 + 六参数 ──▶ 按形态分派
③ 态   ─┘   (相加)       (至少包含)   (SpellParams)    touch / self
                              │
                              └─▶ 写入时把魔法名存进板子（客户端没有反应表）
```

**关键设计**：三个格子是**三次独立查表**，不是三阶排列。
`6 + 6 + 6 = 18 条定义` 覆盖了理论上 `6×6×6 = 216` 种输入。

## 六、数值口径（唯一权威）

### 元素值（六轴：火/水/草/地/风/光，暗 = 负光）

| 强度 | 元素 |
| --- | --- |
| 1.0 | 六种基础元素 + 暗 |
| 1.5 | 霜、砂、烬、芽 |
| 2.0 | 电、晨、影、木 |
| 2.5 | 冰、金 |

**三条约束**：强度上限 2.5 ／ 主分量绝对值必须严格大于修饰分量（避免并列）／ 负值是稀缺资源。

### 衰变时长（NORMAL 档，默认）

| 元素 | 变质时间 |
| --- | --- |
| 光 / 暗 | 6 分钟（有利环境 12 分钟） |
| 水 | 7.5 分钟 |
| 草 | 9 分钟 |
| 火 | 12 分钟（基准） |
| 风 | 13.5 分钟 |
| 地 | 16.5 分钟 |

### 态（第三口）的六个参数

火=烈度 ／ 风=范围 ／ 光=持续 ／ 地=造拆 ／ 水=连锁 ／ 草=极性（伤 ↔ 愈）
