## 一、飞出去的元素（最缺）

### 现在的问题

法术弹射物现在的做法是**把一整瓶元素瓶扔出去**（直接复用元素瓶图标），
看起来像"扔玻璃瓶"，不像"法术飞出去"。

### 要什么

**每种元素一张"飞行中的元素本体"图标**，16×16。

- 不要瓶子、不要容器、不要手
- 要能看出是**一团能量**：中心亮、边缘散
- 拖尾靠代码粒子做，图里**不要画拖尾**
- 建议做成不规则形状，不要圆形规整

## 二、仪式台界面（现在是程序画的）

### 现在的问题

底图是我用代码逐像素画出来的（纯色块 + 虚线），能看但很素。
现在的布局已经改了，需要重画一张。

### 尺寸与结构

**176 × 184**，坐标是**图内像素坐标，从左上角算**。

```
┌───────────────────────────────┐ 0
│  基础仪式台          （标题区）│
├───────────────────────────────┤ 14
│ ┌───────────────────────────┐ │ 16  命名输入框（深底横条）
│ │  名字…                    │ │
│ └───────────────────────────┘ │ 34
│                               │
│        [料] [辅] [态]         │ 45 三个格子：内容 16×16
│                               │
│  ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─   │ 72 分隔虚线
│                               │
│        [板]  →  [产出]        │ 81 两个格子 + 箭头
│                               │
│  物品栏                       │ 102 标题文字位置
│  ┌─┬─┬─┬─┬─┬─┬─┬─┬─┐          │ 112 背包 3×9
│  └─┴─┴─┴─┴─┴─┴─┴─┴─┘          │
│  ┌─┬─┬─┬─┬─┬─┬─┬─┬─┐          │ 170 快捷栏
└───────────────────────────────┘ 184
```

### 需要你做的

1. **面板与边框**：和现有的符文柜、密封仓风格统一
2. **命名输入框**：(10,16) 到 (166,34)，深色底，能衬托白字
3. **三个配料格**：内容区左上角 (62,45)、(80,45)、(98,45)，各 16×16，
   外框 18×18（原版槽位风格：左上暗、右下亮）
4. **中间分隔**：y=72 一条横向装饰（虚线或刻纹）
5. **申明板格 / 产出格**：(62,81)、(98,81)，中间画一个"→"箭头（大约 x 84~92）
6. **背包区**：3×9 格从 (8,112) 起，快捷栏从 (8,170) 起，间距 18
7. 可选：四角加一点装饰花纹（原来那版有，重画时丢了）

> 交付：`assets/elemental_verse/textures/gui/ritual_altar.png`（176×184）
