## 一、这一阶段到底在造什么

一句话：

> 把 03/04 埋下的余热变成**玩家能看见、能感受的压力**，并给出第一层手段。

当前余热是个藏在后台的数值（`/ev heat` 能查），玩家既不感知、也无力应对。
本阶段做的是一整条「污染从哪来 → 长什么样 → 我怎么把家保住」的闭环：

```
区块污染值（读余热 + 衰变残留 + 邻块扩散）
   ↓
三阶可视化（灰绿薄雾 / 粒子，随阶变浓）
   ↓
浊化系统（待得越久叠得越深；脏渍 HUD + 视野）
   ↓
灼喉砂（块 / 沉积 / 气团 → 加速浊化；砂可中和）
   ↓
面部位装备槽（自建）+ 三件防护
   ↓
元素方碑 + 净化仪式（第一层治理手段）
```

**原则（总纲 3.1 的重要前提）**：前两阶一定不能致命——
一个需要绕路的模组，最后会变成一张被绕开的地图。
所以本阶段所有 debuff 都是「变慢、变脏、看得晚」，不做瞬伤、不做一波带走。

## 二、区块污染值（数据地基）

### 2.1 存储

污染强度是一个 **0.0 ~ 1.0 的连续值，按区块存储**。

当前 `ChunkHeat` 用的是 NeoForge 的 `SavedData`（服务端已落盘）。
本阶段直接扩展它，或新开一个污染值载体。**实现建议**放「六、代码结构」。

### 2.2 结算（每 5 秒一次，总纲 3.4）

```
污染值 += 该区块内衰减中的元素量 × 系数      ← 衰变产物堆积
        + 最近的施法余热                     ← 玩家自己的锅
        + 8 邻块传来的一部分                  ← 自然扩散
污染值 ×= 0.999                              ← 自然缓慢沉降
污染值 -= 生物群系/降雨的净化量               ← 雨天、森林会自己压一点
```

- **元素量的系数**：先给默认值，进游戏调。
- **邻块扩散**：每 5 秒把 1/8 的差值匀给 8 邻块（或按邻居差比例流），防止一格格跳。
- 边界：区块卸载 / 加载时扩散要正常衔接（不能让边界突然清空或拉高）。

### 2.3 三阶（总纲 3.1）

| 阶 | 名字 | 阈值 | 玩家感受到 | 机制 |
| --- | --- | --- | --- | --- |
| **一** | **沾尘** | 0.00 – 0.25 | "这地方有点不对" | 灰绿薄雾、环境粒子稀少、作物生长 ×0.8。**无 debuff** |
| **二** | **侵蚀** | 0.25 – 0.60 | 有点烦，但还能干活 | 叠加式浊化（见第三节） |
| **三** | **晶脉** | 0.60 – 1.00 | 该处理了 | 浊化可叠到顶层；晶脉网络开始成型；**1.0 时生成晶脉结节** |

> 三阶的「晶脉网络 / 结节」先留钩子即可，实体与扩张属于阶段 08。本阶段做「位置」与「朝向」。

## 三、浊化（玩家状态，叠加式）

### 3.1 数值（总纲 3.2）

浊化值 `0.0 ~ 100.0`，**纯玩家状态，跨维度/跨区块携带、缓慢消退**。

| 层级 | 浊化值 | 效果 | 性质 |
| --- | --- | --- | --- |
| **0 清** | < 33 | 无 | —— |
| **1 浊** | ≥ 33 | 挖掘疲劳 I、移速 −10% | 只是"变慢" |
| **2 障** | ≥ 66 | 挖掘疲劳 II、移速 −20%、**视野迷雾**（客户端） | 开始影响判断 |
| **3 蚀** | = 100 | 上述全部 + **不主动回血** | 最高级，最该避免 |

### 3.2 累积 / 消退速率（总纲 3.2）

| 所在阶 | 累积 | 叠满所需时间 |
| --- | --- | --- |
| 沾尘 | 0 | —— |
| 侵蚀 | +0.08 /tick | 约 **21 分钟** |
| 晶脉 | +0.25 /tick | 约 **7 分钟** |

- **消退**：离开污染区 **+0.10 /tick**（约 17 分钟退干净）；净化手段 **+1.0 /tick**（秒退）。
- 累积叠加目标：侵蚀区待 21 分钟叠满、晶脉区待 7 分钟叠满 —— 这是手感核心，进游戏必调。

### 3.3 防护装备（减缓加深，不是免疫）

| 装备 | 减缓 | 材料 |
| --- | --- | --- |
| **滤布面罩** | −25% | 布 + 死寂草 |
| **灼喉面罩** | −40% | 滤布 + 砂（中和层） |
| **御瘴背心** | −60% | 灼喉 + 金 + 芽 |
| 三件套合计上限 | **−85%** | （不做 100% 免疫） |

> **面罩戴在头盔槽？不。** 面罩是**独立饰品槽**，玩家要同时戴头盔和面罩。
> 用 NeoForge 的 `curios` 不是必选依赖 —— 我们**自己做一个简化的面部位装备槽**（路线图技术备忘 T5）。

### 3.4 UI 反馈（不显示数字）

- 屏幕边缘在 1/2/3 层时出现**逐渐明显的灰绿脏渍**（叠 1/2/3 层递进）。
- 第 3 层加一层**呼吸式暗角**。
- 玩家"看得见自己脏了"，但**读不出进度**。

## 四、灼喉砂（慢性，不瞬伤）

> 设定让守夜人长期吸入后肺部受损 —— 所以游戏里它是**慢性**的：**不直接掉血，只有浊化。**
> **不做"吸入即掉血"**（总纲 3.3）。

三种形式：

| 形式 | 表现 | 交互 |
| --- | --- | --- |
| **灼喉砂块** | 地面灰绿砂质地 | 走过加速浊化 **×2**；可**用铲子收集**（成物品） |
| **灼喉沉积** | 方块表面薄层（像雪） | 视觉预警；踩上去有粒子 |
| **灼喉气团** | 地底空腔悬浮粒子 | 进入范围加速浊化 **×3**；放**中和块**气团消散 |

生成规则（先在污染区地面/地底刷，群系细节阶段 07 再补）：

- 二阶以上区块开始刷**灼喉沉积**，三阶刷**砂块**；地底空腔刷**气团**。
- 砂块收集 → `灼喉砂` 物品：既是防护材料（灼喉面罩），又是净化仪式投入（见第六节）。

## 七、元素方碑 + 净化仪式（第一层治理手段）

### 7.1 元素方碑（总纲 3.5）

- **3×3 底座 + 中心柱**（不是多方块结构，是「底座 + 可放置的碑」，摆放自由）。
- 需要插入**纯净元素核心**：由 **8 个同种稳定元素 + 1 个芽**合成。
- 核心会衰变 → 大约 **5 游戏日**耗尽 → **必须换**（这就是"没有永久方案"）。
- 作用**半径 16 格**；范围内污染值**只降不升**（圈出安全区）。
- **核心越纯，半径越大**：用光/暗做核心半径 **×1.5**。

### 7.2 净化仪式（总纲 3.5）

- 在仪式台上投入 **`芽 ×4 + 任意元素 ×16 + 灼喉砂中和块`**。
- 选择半径，**分若干轮推进**（每轮间隔一段时间，看得见污染值在退，但快不了）。
- 效果：让污染区**退阶**。想根治就得掏空仓库。
- **中和块**：`灼喉砂 + （配方待定）` 合成，既是气团中和，也是净化仪式材料。

### 7.3 第三层手段（晶裔沟通）

属于阶段 08（`与晶裔沟通让它放缓扩张，付申明板/知识`）。
本阶段**不做**，只在文档里指向 08，避免把 06 做大。

## 十、验收标准（进游戏逐条点）

> 具体命令/贴日志方式见 `../构建与验证.md`。改完内容类文件，落地后按路线图流程走。

- [ ] 在原地**连续施法**（中量级 ×几发），**肉眼看到区域慢慢变灰绿**（二阶及以上）
- [ ] 站在二阶区块 **20 分钟以上** → 屏幕边缘脏渍出现 → 挖掘变慢 → 视野起雾
- [ ] **走出污染区** → 浊化慢慢退掉（约 17 分钟退干净）
- [ ] 戴上三件套 → 同样的时间**只叠到一半**（三件合计 −85% 斜率）
- [ ] 走过灼喉砂块 → 浊化**加速**；用铲子收集 → 得到灼喉砂
- [ ] 放**中和块** → 灼喉气团消散
- [ ] 放下**元素方碑**（插纯净核心）→ 范围内污染值**只降不升**，圈出安全区
- [ ] 核心耗尽（约 5 游戏日）→ 方碑失效，提示换核心
- [ ] 跑一轮**净化仪式** → 污染阶数**明显退了一档**
- [ ] 三阶区块污染物到 **1.0** → 出现晶脉结节钩子位置（可视化可无）
