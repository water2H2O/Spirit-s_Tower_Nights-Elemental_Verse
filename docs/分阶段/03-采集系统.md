## 一、这一阶段要解决什么

阶段 02 结束时，玩家在生存里能拿到的东西只有三样：水元素、霜元素、死寂尘。
其余（地、风、火、草、冰、光、暗）全部只能从创造栏拿。

**本阶段目标：让生存玩家能从世界里采到全部七种元素 + 冰，并且每一种都留好"在家量产"的路。**

后半句是这一版新增的硬约束（总纲 12.1）：
**只解决"第一次怎么拿到"的方案，一律算没做完。**

## 二、统一交互规则

1. 手持**对应的空容器**右键目标 → 容器里装上元素；**容器本身不消耗**（岩浆也不消耗）
2. 一次可装多份的元素（岩浆 5 份）会在一次交互里装满，其余 1 份
3. 容器里**已经有东西** → **静默无反应**（作者定：不提示，避免刷屏）
4. **没有冷却、没有耐久、没有概率**（作者定：同原版水瓶）
5. 成功：轻微音效 + 粒子
6. **只有"条件不满足"才提示**（太暗/太亮/风进不来/风太弱/火已熄灭）

## 三、七种元素 + 冰：完整获取表

### 3.1 地 —— 从**矿物**里取，按稀有度给量

**不再从普通石头取。** 右键矿物方块，产出量与稀有度挂钩：

| 矿物 | 每次产出 |
| --- | --- |
| 煤 / 铁 / 铜（含深板岩变种） | **1** |
| 金 / 红石 / 青金石 / 下界石英 | **2** |
| 钻石 / 绿宝石 / 远古残骸 | **3** |

- 采集**不破坏方块**（作者：不变）
- **可再生路线见总纲 12.2**：地元素可以在家"长"矿物，但**必须与已有岩石接触**
  —— 借用环境元素，不是无中生有。本阶段不做。

### 3.2 水 —— 右键水源（已有，保留）

### 3.3 风 —— 高处 / 雷雨

| 条件 | 产出 |
| --- | --- |
| **露天 + Y ≥ 120** 右键空气 | 1 |
| **雷雨中**（任意高度、露天） | 1 |

**可再生方案待补**（作者：后面再定）。

### 3.4 火 —— 三条路，三种心态

| 途径 | 产出 | 代价 |
| --- | --- | --- |
| **岩浆** | **5 份** | **扣血（6 点 ≈ 3 颗心）** |
| **火焰方块** | **1 份** | 不扣血，但**火被扑灭** |
| **烈焰粉 + 空元素瓶 → 火元素瓶** | **1 份** | 安全、可量产（**可再生基线**） |

**营火不算火**：永燃方块温度不够，右键营火得到 **烬**（EMBER）。

### 3.5 木 —— 树苗 / 枯木 / 树叶（作者 2026-10-17 补充）

右键树苗、枯木、树叶 → **木元素**，方块被采掉。
**不含原木** —— 否则任何一棵树都能无限刷。

### 3.5b 草 —— 会再生

| 目标 | 产出 | 副作用 |
| --- | --- | --- |
| 草方块 | 1 | **变成泥土**（草会从邻近草地自然蔓延回来 → 可再生） |
| 蕨 / 高草丛 / 花 | 1 | **被采掉**（骨粉可再生） |

### 3.6 冰 —— 会衰变，且越采越薄

**冰作为元素态也会衰变**（和其他元素一样，最终变成死寂尘）。

方块侧有"储量"，采一次薄一层：

| 方块 | 可采次数 | 采完变成 |
| --- | --- | --- |
| **蓝冰** | 9 | 浮冰 |
| **浮冰** | 9 | 冰 |
| **冰** | 3 | **消失**（变空气） |

> 冰原因此是**会被采空的资源点**。剩余次数用"维度 + 坐标"的存档数据记录。

### 3.7 光 / 暗 —— 专用容器

| 元素 | 载体 | 条件 |
| --- | --- | --- |
| **光** | 折射棱镜 | **露天 + 天空光 ≥ 12**（白天；**阴雨也算**） |
| **暗** | 聚影瓶 | 所在位置**方块亮度 ≤ 7** |

## 五、小包的冷却：霜 = 半个冰

| 冷却剂 | 倍率 | 烧掉间隔 |
| --- | --- | --- |
| 霜 | ×0.8 | **30 秒一个** |
| 冰 | ×0.5 | **60 秒一个** |

同样占一格，冰的实际价值约为霜的两倍（总纲 12.6）。

## 七、验收标准

**开一局生存，全程不开创造栏：**

- [ ] 空手做元素瓶 → 右键**煤矿**得 1 土元素，右键**钻石矿**得 3 土元素
- [ ] 右键水 → 水元素（不回归）
- [ ] 采**草方块** → 草元素，方块变泥土；**过一阵草长回来**
- [ ] 右键**营火** → 得到**烬元素**（不是火）
- [ ] 右键**火焰方块** → 火元素 ×1，**火熄灭**，不扣血
- [ ] 右键**岩浆** → 火元素 ×5，**扣 6 点血**
- [ ] **烈焰粉 + 空元素瓶 → 火元素瓶**（工作台）
- [ ] Y ≥ 120 露天右键 → 风元素；洞里 → 「风进不来」
- [ ] 冰原：连续采**冰方块**，**第 3 次后方块消失**
- [ ] 采**浮冰** 9 次 → 变成冰
- [ ] 冰元素**会衰变**
- [ ] 白天露天用**折射棱镜** → 光元素；洞里 → 「这里没有光可捉」
- [ ] 暗处用**聚影瓶** → 暗元素；白天露天 → 「这里太亮了」
- [ ] 容器装着东西时右键 → **静默**
